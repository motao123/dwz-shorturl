/ Quickstart

快速开始

三分钟跑起来，Docker 一条命令搞定全部依赖。

docker-compose.yml 
# 推荐：Docker Compose 一键起服务
git clone https://github.com/motao123/dwz-shorturl.git
cd dwz-shorturl
cp deploy/.env.example deploy/.env   # 填 DB/Redis/JWT 配置
docker compose -f deploy/docker-compose.yml up -d
本地开发 
# Go 后端
cd backend
cp configs/config.example.yaml configs/config.yaml
go run ./cmd/server

# Vue3 管理台
cd frontend && npm install && npm run dev

# 幂等迁移（schema_migrations）
go run ./cmd/migrate -status
