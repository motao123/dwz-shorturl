## Functional and Business Validation

### DWZ-H-03

| Scenario | Expected result | Result |
|---|---|---|
| Create with a domain | Insert and counter increment occur together | PASS |
| Create without a domain | No domain counter update | PASS |
| Create the same URL twice | Existing record returned; no double increment | PASS |
| Change a link's domain | Old counter decremented, new counter incremented | PASS |
| Save without changing domain | No counter changes | PASS |
| Single delete | Delete and decrement occur together | PASS |
| Batch delete three links on one domain | Counter decreases by exactly three | PASS |
| Delete a missing record | No counter change | PASS |

Atomicity is implemented in GORM transactions. Counter updates require exactly one matching domain row; otherwise the transaction is rolled back.
