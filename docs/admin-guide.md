# 管理后台使用手册（运营视角）

> 面向**平台运营 / 管理员**。技术设计与数据模型见 [BACKEND_ADMIN_DESIGN.md](./BACKEND_ADMIN_DESIGN.md)。
> 后台地址：`https://<你的域名>/admin/`，账号由部署时设置（Docker 用 `ADMIN_USERNAME` / `ADMIN_PASSWORD`；源码部署由 `setup.php` / `createadmin` 设置）。

---

## 1. 首次登录与安全设置

1. 打开 `/admin/`，输入管理员账号密码登录。
2. 首次登录请立刻修改密码：`系统设置 → 个人资料 → 修改密码`。
3. **开启 2FA**：`个人资料 → 两步验证`，用 Google Authenticator / 微软 Authenticator 扫码绑定，输入 6 位验证码确认。绑定后务必保存恢复码 —— 手机丢失时它是唯一的找回方式。
4. 会话策略：登录令牌 2 小时过期，刷新令牌 7 天；退出登录会将令牌加入 Redis 黑名单。

> 忘记密码且无法登录后台时：在服务器上设置 `RESET_ADMIN_PASSWORD=1` 重启 init 容器（Docker），或执行 `cd backend && go run ./cmd/createadmin -reset`（源码部署）。

## 2. 角色与权限（RBAC）

采用「角色 → 权限点」模型，共 4 级内置角色、22 个权限点。

| 角色 | 典型用途 | 大致权限范围 |
|---|---|---|
| `super_admin` 超级管理员 | 站长本人 | 全部权限，含用户/角色/系统设置 |
| `admin` 管理员 | 运营负责人 | 短链、会员、统计、域名池、Webhook、审计日志（不可改系统设置与角色） |
| `operator` 操作员 | 日常运营 | 短链增删改查、查看统计（不可管理用户与系统设置） |
| `viewer` 只读 | 数据查看 | 只读列表与统计 |

**常用配置示例**

- 新增一个「只管理短链、不能看用户」的运营号：`角色管理` 新建角色，勾选 `short_url:*` + `stats:read`；再到 `用户管理` 新建用户并分配该角色。
- 权限点命名规则为 `资源:动作`（如 `short_url:delete`、`api_keys:create`、`domain:write`），按需勾选即可。

> 权限变更后用户需**重新登录**才会生效（权限写入 JWT 声明）。

## 3. 短链管理

- **列表**：支持按短码 / 目标地址搜索，按状态、域名、创建人、时间范围筛选，可切换分页大小。
- **新建**：填写目标 URL 即可；可选自定义短码（6–8 位 `a-z0-5`）、有效期（永久/1/7/30/365 天）、域名池域名、访问密码。
- **编辑**：可改标题、有效期、状态、分类、密码。密码留空 = 不修改，填写 = 覆盖。
- **批量操作**：批量启用 / 禁用 / 删除 / 导出 CSV。
- **回收站**：删除的短链进入回收站，可恢复；超过保留期由定时任务物理清理。
- **公共库同步**：管理端数据会同步到前台 `wjoy_log`。若同步失败，接口会返回 `public_sync_failed: true`，页面会显式告警 —— **不要忽略该提示**，需重试或联系运维排查。

## 4. 数据统计

| 模块 | 指标 |
|---|---|
| 概览卡片 | 短链总数、总点击、今日点击、活跃短链数 |
| 趋势折线 | 按日点击量（可切时间范围） |
| Top10 柱状 | 点击量最高的短链 |
| 单链详情 | 点击趋势、Referer 来源归类、国家/地区分布（需配置 GeoIP）、时段热力图 |

> 国家/地区分布依赖 `geoip.db_path` 指向 ip2region 数据库；未配置时该维度为空，其余指标不受影响。

## 5. 域名池

1. `域名池 → 新增域名`：填写域名、协议（http/https）、别名，并选择是否启用。
2. 添加后系统会定期做 DNS / SSL 健康检查，健康状态与到期时间在列表中展示。
3. 创建短链时可选择域名；**未选择时使用主域名**。
4. 负载均衡：开启后新短链会在启用中的域名间轮询分配。

> 若前台或会员中心的下拉框为空，通常是 `/admin/api/` 反代未配置，见 [deploy-baota.md](./deploy-baota.md)。

---

## 6. API 密钥

1. `API 密钥 → 创建密钥`：填写名称、每分钟配额、有效期。
2. **明文密钥只在创建弹窗中展示一次**，请立即复制保存。关闭后无法再次查看（服务端只存 SHA-256 哈希）。
3. 列表可查看每个密钥的用量（总请求 / 今日请求 / 近期趋势），支持吊销。
4. 调用方式见 [API 文档](../api.html) 的「方式二：API 密钥调用」。

---

## 7. Webhook

- 支持事件：`link.created`、`link.clicked`、`link.expired`、`link.deleted`。
- 创建订阅时填写回调 URL（必须是公网可达的 http/https 地址），可选签名密钥。
- 投递记录：`Webhook → 投递记录`可查看每次请求的状态码、耗时与响应摘要；失败的投递支持手动重试。
- 投递失败会按退避策略自动重试，连续失败次数过多会暂停订阅并告警。

---

## 8. 违规内容检测

- 内置菠菜 / 仿冒 / 恶意关键词库，判定结果三态：`blocked` 拦截、`review` 待人工复核、`passed` 通过。
- `违规检测` 页可按状态筛选，人工复核可改判并记录审计。
- 建议开启 `blocked` 自动拦截，`review` 保留人工通道，避免误伤正常业务链接。

---

## 9. 审计日志

- 记录所有写操作：操作人、IP、资源类型、动作、JSON 详情、时间。
- 支持按操作人 / 资源类型 / 时间范围检索。
- 审计日志只读且不可删除（除定时清理），是排查「谁改了什么」的唯一依据。

---

## 10. 实时监控

系统健康面板展示：

| 指标 | 正常参考 | 异常处理 |
|---|---|---|
| 数据库连接池（open / in-use / idle） | idle > 0 | in-use 持续打满 → 检查慢查询、调大连接池 |
| Redis 状态 | connected | 掉线会导致限流退化为单机计数、令牌黑名单失效 |
| Goroutine 数量 | 稳态波动 | 持续单调上升 → 疑似协程泄漏，抓 pprof |
| 服务运行时长 | 与部署时间一致 | 频繁重启 → 看容器日志 |

`GET /health` 是同一份数据的外部探针接口，可直接接入监控告警。

## 11. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 域名池下拉为空 | `/admin/api/` 未反代，见 [deploy-baota.md](./deploy-baota.md) |
| 短链删除成功但前台仍能跳转 | 公共库同步失败，刷新列表看告警，重试删除 |
| 创建 API 密钥拿不到明文 | 后端版本过旧，升级到含扁平化契约的版本 |
| 会员收不到验证邮件 / 重置邮件 | 未配置 SMTP，见 README「邮件配置」 |
| 统计页国家分布为空 | 未配置 GeoIP 数据库 |
| 令牌频繁失效 | 检查 `jwt.secret` 是否每次重启都变（应固定在配置中） |
