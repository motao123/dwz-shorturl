API 文档

短网址服务提供 RESTful 风格的 HTTP 接口，支持单条生成、批量生成、短链跳转与统计查询。

概述

  • 所有生成接口均为 application/x-www-form-urlencoded 的 POST-only 接口。GET 或其他方法返回 HTTP 405 和 Allow: POST 头。
  • 成功响应默认返回 JSON（Content-Type: application/json; charset=utf-8）。
  • 短链 URL 由服务端配置 $public_base_url 决定，格式为 {base_url}/{short_code}。
  • 部署在子目录时，所有路径自动适配相对 URL。

单条生成：POST api.php

请求参数

参数必填说明
url是目标网址。仅接受 http/https，最长 2048 字节，不可含控制字符或 URL 凭据
custom否自定义短码，6–8 位 [a-z0-5]。留空则自动生成
expire否有效天数：0(永久) / 1 / 7 / 30 / 365，默认 0
format否设为 txt 时返回纯文本短链（成功）或错误文本（失败）

curl 示例

curl -X POST https://1.xk7.cn/api.php \
  -d "url=https://example.com/long-page" \
  -d "custom=mylink" \
  -d "expire=30"

成功响应 (HTTP 200)

{
  "code": "mylink",
  "msg": "success",
  "result": 1,
  "short_url": "https://1.xk7.cn/mylink",
  "state": "created"
}

state 取值：

值含义
created新建短链
existing相同目标 URL 已存在，返回已有短码
renewed已有短链已过期，续期后返回

批量生成：POST batch.php

请求参数

参数必填说明
urls是换行分隔的 URL 列表。最多 100 行，原始 body 最长 210000 字节
注意：批量接口不支持 custom 和 expire 参数，所有短链均使用随机短码且永久有效。

curl 示例

curl -X POST https://1.xk7.cn/batch.php \
  --data-urlencode "urls=https://example.com/a
https://example.com/b
https://example.com/c"

成功响应 (HTTP 200)

返回 JSON 数组，每个元素独立表示成功或失败：

[
  {
    "url": "https://example.com/a",
    "code": "abc123",
    "short_url": "https://1.xk7.cn/abc123",
    "msg": "success",
    "result": 1
  },
  {
    "url": "http://127.0.0.1/",
    "code": null,
    "short_url": "",
    "msg": "url host not allowed",
    "result": 10004
  }
]
请求级错误（空列表、超 100 条、body 过大、限流、方法错误）返回单个 JSON 对象而非数组，HTTP 状态码非 200。

短链跳转：GET /{code}

通过 Web 服务器重写规则，/{6-8位短码} 映射到 do.php?uid={code}。

HTTP 状态条件
302短码有效且未过期，重定向到目标 URL，同时点击计数 +1
404短码格式无效或不存在
410短链已过期，或目标 URL 未通过安全校验
500数据库查询异常

所有跳转响应携带缓存控制头：

Cache-Control: no-store, private, max-age=0
Pragma: no-cache
Expires: 0

统计页：GET stats.php

私有统计页面，需通过请求头传递 Token 认证：

Header说明
X-Stats-Token: <token>主要认证方式
Authorization: Bearer <token>备选认证方式
安全机制：当 $stats_enabled = false 或 $stats_token 为空时，stats.php 对所有请求返回 404，绝不泄露统计功能的存在。Token 比较使用 hash_equals() 防止时序攻击。

页面展示内容：

  • 短链总数
  • 累计点击总数
  • 点击量 Top 10
  • 最近创建的 20 条短链

安全响应头：

Cache-Control: no-store
X-Robots-Tag: noindex, nofollow
X-Content-Type-Options: nosniff
Referrer-Policy: no-referrer

速率限制

接口限制窗口计费
api.php20 次60 秒每次请求 cost = 1
batch.php100 次60 秒cost = URL 条数
  • 基于客户端 IP 的文件锁滑动窗口计数器。
  • 仅当 REMOTE_ADDR 匹配 $trusted_proxies 配置时才信任 X-Forwarded-For 头。
  • 限流目录不可写时请求直接失败（fail-closed）。

SSRF 防护

在创建和跳转两个阶段均执行目标 URL 安全校验：

  • 仅接受 http / https 协议
  • 拒绝含 URL 凭据（user:pass@host）的地址
  • 拒绝控制字符、非法端口
  • 拒绝 localhost、*.local 主机名
  • DNS 解析后拒绝所有私有/保留 IPv4/IPv6 地址
  • DNS 解析失败直接拒绝
建议：SSRF 校验为应用层防护，建议同时在主机/容器层面配置出站防火墙规则作为纵深防御。
